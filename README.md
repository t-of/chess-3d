# chess-3d — チェス入門：ルールを 1 から

立体の盤で、チェスを 1 から学べる入門。駒の動かし方からチェックメイトまで、触って覚える。2 人で自由に指すこともできる。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/chess-3d/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

- タイトルから「つづきから」「レッスン一覧」「自由に指す」を選ぶ。今は第 1 章（盤と駒・ルーク・ビショップ・クイーン・キング・ナイト・ポーン）の 7 レッスン。あとの章は順に足していく。
- レッスンは「説明 → お題 1〜3 問」。どのレッスンからでも始められ、クリアすると一覧に ✓ が付く。
- 駒をタップ → 光った升をタップで指す。白を動かすのはいつも自分。ちがう手は元に戻り、ひとこと出る。2 回まちがえるとヒント（黄色い升）が出る。
- 「自由に指す」は 2 人で交互に指す対戦（AI なし）。手番が変わると視点が相手側へ回る。キャスリング・アンパッサン・プロモーション（クイーン固定）・チェックメイト / ステイルメイトに対応。
- ドラッグで盤を回し、ピンチ / ホイールで寄る。右上の「音」で効果音を切れる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。three.js（r170）は `vendor/` に入れてある。ルール判定は `chess.js`（`node chess.js` で perft などを確認）、レッスンのデータと判定は `lessons.js`、効果音は `sound.js`。レッスンを足したら `node lessons.test.mjs`（全レッスンの見本の手を流して合格になるか確かめる）を通す。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
